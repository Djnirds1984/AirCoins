                        Pin numbers are PHYSICAL header pins (the numbers printed on the 40-pin header),
                        not BCM/sunxi GPIO numbers. The kernel GPIO line is shown next to each pin
                        — e.g. Orange Pi PC pin 3 = PA12 = GPIO 12.
                        Pins marked with a function (I2C/SPI/UART) only work as GPIO when that overlay is disabled.
